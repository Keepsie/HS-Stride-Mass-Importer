HS STRIDE MASS IMPORTER CORE - LLM API REFERENCE
================================================
Version: 1.1.0 | .NET 8.0 | Package: HS.Stride.Mass.Importer.Core
Copyright (c) 2025 Happenstance Games LLC | Apache License 2.0

Bulk import assets (textures, models, audio, fonts) into Stride projects.
Automatically creates Stride asset files (.sdtex, .sdm3d, .sdsnd, etc.) and optional materials.

================================================================================
QUICK START
================================================================================

```csharp
using HS.Stride.Mass.Importer.Core;

var importer = new StrideMassImporter();

// Import assets into Stride project
var result = await importer.ImportAssetsAsync(
    packageName: "MyAssets",
    sourceFolder: @"C:\UnityAssets\MyPack",
    strideProjectPath: @"C:\MyStrideGame",
    createMaterials: false);

if (result.Success)
{
    Console.WriteLine($"Imported {result.AssetsCreated} assets");
    Console.WriteLine($"Assets: {result.TargetAssetsPath}");
    Console.WriteLine($"Resources: {result.TargetResourcesPath}");
}
else
{
    Console.WriteLine($"Failed: {result.ErrorMessage}");
}
```

================================================================================
SUPPORTED FILE TYPES
================================================================================

| Type     | Extensions                      | Stride Output | SubFolder |
|----------|--------------------------------|---------------|-----------|
| Texture  | .png .jpg .jpeg .bmp .tga .dds | .sdtex        | Textures  |
| Model    | .fbx .obj .dae .gltf .glb      | .sdm3d        | Models    |
| Audio    | .wav .mp3 .ogg .flac           | .sdsnd        | Audio     |
| Font     | .ttf .otf .ttc .woff .woff2    | .sdfnt        | Fonts     |
| RawAsset | .json .xml .txt .csv           | .sdraw        | Data      |
| Code     | .cs                            | .cs           | Code      |

Ignored Files:
  .meta, .tmp, .temp, .log, .bak, .old, thumbs.db, .ds_store, desktop.ini

OUTPUT STRUCTURE
================================================================================

After importing "MyPack" into a Stride project:

Assets/MyPack/
├── Textures/
│   └── texture_name.sdtex
├── Models/
│   └── model_name.sdm3d
├── Materials/                     # If createMaterials=true
│   └── texture_name_Mat.sdmat
├── Audio/
│   └── sound_name.sdsnd
├── Fonts/
│   └── font_name.sdfnt
└── Data/
    └── config.sdraw

Resources/MyPack/
├── texture_name.png               # Raw files copied here
├── model_name.fbx
└── sound_name.wav

REAL-WORLD USAGE PATTERN (from HS-Stride-UI-Editor)
================================================================================

```csharp
// Pattern: Copy files to temp folder, import, cleanup

var importer = new StrideMassImporter();

// Create temp folder with selected files
var tempFolder = Path.Combine(Path.GetTempPath(), $"HS_Import_{Guid.NewGuid():N}");
Directory.CreateDirectory(tempFolder);

try
{
    // Copy files to import into temp folder
    foreach (var file in selectedFiles)
    {
        var destPath = Path.Combine(tempFolder, file.FileName);
        File.Copy(file.FullPath, destPath, overwrite: true);
    }

    // Run the import
    var result = await importer.ImportAssetsAsync(
        packageName: "Textures",
        sourceFolder: tempFolder,
        strideProjectPath: projectPath,
        createMaterials: false);

    if (result.Success)
    {
        // Assets now available at result.TargetAssetsPath
        // Raw files at result.TargetResourcesPath
    }
    else
    {
        // Handle error via result.ErrorMessage
    }
}
finally
{
    // Cleanup temp folder
    try { Directory.Delete(tempFolder, recursive: true); }
    catch { /* ignore cleanup errors */ }
}
```

COMMON PATTERNS

### Import Unity Asset Pack
```csharp
var importer = new StrideMassImporter();
var result = await importer.ImportAssetsAsync(
    "SyntyPolygon",
    @"C:\UnityAssets\PolygonFantasy",
    @"C:\MyStrideGame",
    createMaterials: true);
```

### Preview Before Import
```csharp
var preview = importer.PreviewImport(@"C:\UnityAssets\MyPack");
Console.WriteLine($"Textures: {preview.GetTextureCount()}");
Console.WriteLine($"Models: {preview.GetModelCount()}");
Console.WriteLine($"Audio: {preview.GetAudioCount()}");
Console.WriteLine($"Total: {preview.GetTotalFileCount()}");
```

### Check If Package Exists
```csharp
if (importer.PackageExists("MyPack", @"C:\StrideGame"))
{
    Console.WriteLine("Package already imported - will update existing files");
}
```

### Full Validation
```csharp
var validation = importer.ValidateInputs(packageName, sourceFolder, projectPath);

if (!validation.IsValid)
{
    foreach (var error in validation.Errors)
        Console.WriteLine($"Error: {error}");
    return;
}
```

### Access Scan Results
```csharp
var scan = importer.PreviewImport(sourceFolder);
foreach (var item in scan.Items)
{
    Console.WriteLine($"{item.AssetType}: {item.FileName} -> {item.AssetPath}");
}
```

================================================================================
VALIDATION RULES
================================================================================

Package Name:
  - Cannot be empty or whitespace
  - Cannot contain: / \ : * ? " < > |
  - Valid: "MyPack", "Synty_Fantasy", "vfx-pack-01"
  - Invalid: "My/Pack", "Pack:01", "My*Assets"

Source Folder:
  - Must exist
  - Should contain importable files
  - Warning if empty

Stride Project:
  - Must contain .sln file
  - Must contain .sdpkg file(s)
  - Supports Fresh and Template structures

================================================================================
ERROR HANDLING
================================================================================

```csharp
var result = await importer.ImportAssetsAsync(...);

if (!result.Success)
{
    Console.WriteLine($"Failed: {result.ErrorMessage}");
}

if (result.HasErrors)
{
    foreach (var error in result.Errors)
        Console.WriteLine($"Error: {error}");
}

if (result.HasWarnings)
{
    foreach (var warning in result.Warnings)
        Console.WriteLine($"Warning: {warning}");
}

// Full report
Console.WriteLine(result.GetReport());
```
